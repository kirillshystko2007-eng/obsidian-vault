# Управление
Часть [[MM 00 - Обзор]].

| Ввод | Действие |
|---|---|
| Палец на левой/правой половине экрана | Руль влево/вправо (мультитач по `pointerId`) |
| Обе половины сразу | Тормоз |
| ← → / A D | Руль |
| ↓ / S / Пробел | Тормоз |
| P / Esc | Пауза |
| M | Музыка вкл/выкл |
| Enter (в меню) | Старт |

Опция «Руль»: **МЯГКИЙ** (assist 0.72, мотоцикл сам держит изгиб дороги) или **ТОЧНЫЙ** (assist 0.4). Используется в [[MM 05 - Физика мотоцикла]].

При потере фокуса окна весь ввод сбрасывается. Подсветка левой/правой «педали» в HUD: [[MM 14 - Интерфейс и язык]].
