# Архитектура и слои
Связано: [[PE 00 - Обзор]], [[PE 02 - Серверные сервисы]], [[PE 03 - Клиентские контроллеры]], [[PE 04 - Сетевые контракты]], [[PE 21 - Структура карты]].

```text
Workspace ── world triggers/data ──> ServerScriptService
ServerStorage ── templates / bindable APIs ──> server
server <── RemoteEvents / attributes ──> StarterPlayerScripts
ReplicatedStorage = shared remotes, modules, animations, catalog, zones
```

**Сервер авторитетен** для урона, Cash/Kills, выдачи предметов, spawn NPC и teleport. Клиент строит UI, читает ввод, запускает локальные анимации и визуальные эффекты. Не принимай `FireServer` за безопасное действие: нужно прочесть server listener и его проверки.

Основные точки: `Workspace` содержит активный мир; `ServerScriptService` — 18 server Scripts + `DeathAnimations`/`HitZones`; `ReplicatedStorage` — 16 direct children и 13 578 descendants; `ServerStorage` — 25 direct children и 33 073 descendants; `StarterPlayerScripts` — 27 LocalScripts; `ReplicatedFirst.IntroCover` — раннее покрытие. `StarterGui` пуст в Edit snapshot.

Контент и правила могут жить в разных местах: world pickup в Workspace, шаблон в ServerStorage, clone в Backpack/Character. NPC behavior может быть скриптом внутри Model, не сервисом в ServerScriptService. Проверяй три места перед правкой системы.
