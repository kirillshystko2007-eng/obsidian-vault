# ZS 05 — Ассеты, бэкапы и инструменты

Связано: [[ZS 00 - Обзор]] · [[ZS 03 - Хаб, базы и рейды]] · [[ZS 06 - Риски и очередь аудита]]

## Ассеты в ReplicatedStorage

| Папка | Содержимое |
|---|---|
| `BossMeshes` (486) | Blender-меши 20 боссов + `_Markers`; надеваются на блочного босса через `BossSkins` (атрибуты на каждом меше) |
| `BossAccessories` (52) | аксессуары боссов |
| `MobMeshes` (70) | Armored, Tank, Toxic, Exploder, Shambler, Runner, Military, Elite, Police, Guard → `MobSkins` |
| `CarMeshes` (104) | Bus, Sedan, Taxi, Hatch, Police, Pickup, Van, Tank, PlaneProp, Jet, Airliner → `Shared.CarKit` (атрибуты Rel / BaseSize, версия-«развалина») |
| `EggMeshes` (40) | меши яиц |
| `ZombieMobs` (13 115) | 40 моделей зомби в 7 папках редкости: `1_Common` … `7_Secret` (KingZombie, TitanZombie). У 7 моделей стандартный `AnimateScript` (LocalScript, 972 строки) |
| `ZombieHeroKit` | 7 MeshPart для героя-зомби (переход на меши 2026-11-18, `*_pre_meshhero`) |
| `UIAssets.SurvivorBrain` | AI-сгенерированный мозг для BrainMenu |

`MaterialService`: `HordeHatchMaterials` + 30 `AssistantMaterials` (HH_CrackedConcrete, HH_ScratchedPlate, HH_RustSteel, HH_Corrugated, HH_WornPlanks, HH_DirtyGround …). CollectionService содержит сотни тегов `RBXAI-TexturedMesh-TextureGen-*` / `Assistant-*`: следы генерации в Studio Assistant. Рабочие теги игры: `PortalScreen, PortalBeacon, PortalSpark, PortalPulse, PortalBlink, PortalSpinUI, RigEdit`.

Звук: эффекты из лицензированной библиотеки (`Config.Sounds`, 43 шт.), музыка APM: хаб 9042593925, забег 9039269632, босс 9043180551.

## DevTools-билдеры (`ServerStorage.DevTools`, только в режиме редактирования)

Запуск из командной строки Studio: `require(game.ServerStorage.DevTools.<Имя>).Build()`. У Expander-модулей `Run(true)` — пробный прогон (только отчёт), `Run(false)` — применить.

| Модуль | Что строит |
|---|---|
| HubBuilder | хаб «GROUND ZERO» (кратер, светящееся яйцо) |
| RetroHubBuilder | альтернативный лобби «BRICKVILLE» в стиле 2007 года (результат в `HubBackups.Hub_RetroBrickville`) |
| HubDressing / HubFortify | карантинный периметр, детали; вышки и укрепления |
| MuseumBuilder / MuseumExpander | Zombie Records Museum |
| MotionLabBuilder / MotionLabExpander | Motion Lab (больница-инкубатор) |
| MutationChamberBuilder | Mutation Chamber + `Dress` (оформление лаборатории) |
| UpgradeStationBuilder / UpgradeGuideBoard | мастерская Rusty и табличка |
| PortalOutpostBuilder | визуал портала |
| CityBackdropBuilder | 13 зданий-задников (порт `D:\RobloxCity\city.py`) |
| PropKit / PropPlacer | пропсы постапокалипсиса и их расстановка с проверкой зазоров (локальные копии в `D:\RobloxCity\`) |

Внешние исходники, на которые ссылается код: `D:\RobloxAnim\anim.py` + `zombie_locomotion.blend` (генерирует `ZombiePose.Clips`, руками не править), `D:\RobloxCity\*.py / *.lua`.

## Прочие папки ServerStorage

`MobMeshes_src`, `CarMeshes_src`, `EggMeshSources`, `EggMeshRejects`, `ZombieMobSources`, `BossMeshes_v1`, `BossMeshes_removed` — исходники и отбраковка мешей. `QA_Tex`, `QA_BossLayout`, `ACC_Stage`, `HH_VFXSprites(2)` — тестовые и рабочие материалы. `_AnnexDisplaced` — то, что сдвинул аннекс баз. `HubBackups` — Hub_RetroBrickville, OldCarWrecks.
