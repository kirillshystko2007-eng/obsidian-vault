# Деньги, убийства и награды
Связано: [[PE 11 - Урон и киллы]], [[PE 14 - Арсенал]], [[PE 16 - Discovery]], [[PE 20 - HUD]].

Атрибут `Cash` отображает валюту. `StartingCash` задаёт стартовое значение (точная сумма требует полного чтения скрипта). `DiscoveryService` начисляет 25 за первое открытие каждой зоны текущей сессии. `KillTracker` прибавляет атрибут `Bounty` жертвы в Cash при зачёте убийства и увеличивает `Kills`. HUD анимирует изменение атрибутов.

Ключевой принцип — сервер хранит решение. Покупка не должна подтверждаться суммой, присланной клиентом; сервер сам вычисляет стоимость и списание. Discovery name/count/reward в remote — серверные параметры, но клиент всё равно только UI. Сохранение Cash между сессиями отдельно не установлено; не путать Roblox Player attribute с DataStore persistence.

При аудите проверить все writes по `SetAttribute("Cash")`, негативные балансы, повторные начисления, гонки покупок, kill-credit дважды, PlayerRemoving/save flows и порядок выдачи предмета. Поиск по всему DataModel даст копии из backups; см. [[PE 23 - Tools и backups]].

## Магазин и сохранение (2026-10-27)

- Цены в `ReplicatedStorage.ArmoryCatalog` (`price`): Clinton 0, Joey 150, C&A 300, RustyBuster 500; `Catalog.StartingCash = 250`. Покупка разовая → атрибут игрока `Owns_<id>=true`.
- `ServerScriptService.Economy` (ModuleScript) — единственное место, где тратится Cash: `Economy.buy(player, id)` без yield (нет гонки двойной покупки). Используют `ArmoryService.equip` и `RevolverPickupHandler` (витрины у ArmoryOwner).
- `ServerScriptService.PlayerData` — DataStore `PE_PlayerData_v1`, ключ `u_<UserId>`: Cash, Kills, Owned. Автосейв 120 с, PlayerRemoving, BindToClose. Пока профиль не загружен — не сохраняет (сбой загрузки не затрёт данные). Заработанное до загрузки прибавляется к сохранённому. В Studio без API access загрузка падает → сессия не сохраняется (ожидаемо).
- Клиент: `ArmoryClient` показывает цену / OWNED / FREE и кнопки BUY / NO CASH; `InteractionPromptStyle` пишет на витрине «Buy $N» / «Need $N». Только отображение — решает сервер.
- Backup: `_AnimBackup.Economy_pre_shop_2026-10-27`.
