# AI GameDev Knowledge Base / База знаний по игровому ИИ

Двуязычная энциклопедия для Obsidian: русский текст + English terminology.
Охват: engine-agnostic Game AI, Unity, Unreal Engine, Godot, Python, ML/RL, LLM NPC, procedural generation.

## Импорт
1. Распакуйте архив.
2. В Obsidian выберите **Open folder as vault / Открыть папку как хранилище**.
3. Укажите папку `Obsidian_AI_GameDev_Knowledge_Base`.
4. Откройте `00 - Dashboard/AI GameDev - Home.md`.
5. Рекомендуемые community plugins: Dataview (необязателен), Templater (необязателен), Tasks (необязателен). База работает и без них.

## Структура
- `00 - Dashboard` — стартовая страница и карта базы.
- `01 - Foundations` — основы игрового ИИ.
- `02 - Decision Systems` — FSM, Behavior Trees, GOAP, Utility AI.
- `03 - Navigation` — pathfinding и steering.
- `04 - Machine Learning` — ML, RL и обучение агентов.
- `05 - LLM NPC` — языковые модели в играх.
- `06 - Procedural Generation` — генерация контента.
- `07 - Engines` — Unity, Unreal Engine, Godot.
- `08 - Python` — Python toolchain.
- `09 - Production` — тестирование, производительность, безопасность.
- `10 - GitHub Library` — каталог внешних проектов.
- `11 - Roadmaps` — учебный план.
- `90 - Templates` — шаблоны заметок.

## Статусы источников
- **Verified in research** — репозиторий/страница открыты при подготовке этой версии.
- **Reference** — известный первичный источник, но детали версии/лицензии следует перепроверить перед использованием.
- **Candidate / verify** — ссылка из первоначального списка; проверить доступность, содержание и лицензию самостоятельно.

Не считайте карточку проекта подтверждением совместимости с вашей версией движка. Проверяйте README, releases, license, supported versions и commit activity на странице проекта.

## Метод работы
Сначала читайте концептуальную заметку, затем официальную документацию, после этого запускайте минимальный пример. Не начинайте с копирования большого проекта в production.
