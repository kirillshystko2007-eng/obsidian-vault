# ZS 01 — Архитектура и сеть

Связано: [[ZS 00 - Обзор]] · [[ZS 02 - Игровой цикл и контент]] · [[ZS 04 - Данные и сохранение]] · полная карта со связями из кода: [[ZS 08 - Карта плейса]]

## Принципы (из шапок модулей)

- **Сервер решает всё.** Клиент только рулит своим персонажем (полоса, прыжок) и *просит* (Dash / Slam / Shield / Pause / каст мутации). Монеты, рекруты, убийства, XP, гемы, урон и награды клиент никогда не сообщает.
- **Сервер шлёт числа и атрибуты, клиент строит всё сам.** Орда, роботы, боссы, декорации дороги, детали баз и станции питомцев строятся и анимируются **локально** (BulkMoveTo, RenderStepped). Сервер держит только невидимые якоря с атрибутами, поэтому зомби-последователи не нагружают сеть и серверную физику.
- **Одна таблица для UI и сервера.** `Shared.Config` / `Shared.Odds` / `Shared.Economy`: шансы яиц и цены считаются одной и той же математикой на обеих сторонах.
- Каждый сервис — ModuleScript с `Init()`. Единственный серверный Script — `ServerScriptService.Main`, плюс отдельный `MutationChamber`.

## Порядок запуска (`ServerScriptService.Main`)

`CharacterService → Net → RunSessionService → EggService → BaseService → FortService → RaidService → CompanionService → MutationService → ShopService → ProgressService → WardrobeService (SetRedress) → DataService.Init()`. Слушатели подключаются первыми (через `DataService.Loaded`), загрузка данных стартует последней.

## Ремоуты (`ReplicatedStorage.Remotes`)

| Ремоут | Тип | Направление | Содержимое |
|---|---|---|---|
| `ShopRequest` | RemoteFunction | клиент → сервер | все действия вне забега через `Net` |
| `RunRequest` | RemoteEvent | клиент → сервер | `Start, Exit, Pause, Resume, IntroDone, MutAbility, LabForm, LabEndForm, LabEvent` |
| `RunEvent` | RemoteEvent | сервер → клиент | 74 вида событий забега (ниже) |
| `ProfileSync` | RemoteEvent | сервер → клиент | только чтение: вид профиля для UI (`Controllers.ClientState`) |

### Net-действия (33)

- **Egg:** BuyEgg
- **Base:** UnlockZone, CollectPet, Collect, GoToBase
- **Companion:** Equip, Unequip, Place, MoveSlot, Unplace, Release, BuyUpgrade
- **Shop:** BuyShopItem, ClaimDaily, SelectMap, Leaderboard, *DebugGrant*
- **Progress:** Forms, ClaimMission, Cosmetic, *DebugProgress*
- **Wardrobe:** OpenCase, EquipWardrobe
- **Fort:** FortUpgrade, FortDefense
- **Raid:** RaidTargets, RaidGoTo, *DebugRaid*
- **Mutation:** MutCapsule, MutEquip, MutUnequip, MutUpgrade, MutEvolve

*Debug-действия регистрируются только при `RunService:IsStudio()`. DebugRaid к тому же отключает сохранение игрока.*

### RunEvent (74 вида)

Забег: `Started, Ended, Returned, Error, PortalEnter, PortalBurst, Segments, Biome, Hit, ShieldHit, Recruit, Smash, Wreck, Float, Pickup, Collected, Squad, RobotAttack, JetStrike, Sniper, Boom, Slam, SlamLand, Sprint`.
Босс: `BossStart, BossAnim, BossTele, BossImpact, BossMove, BossWeak, BossRing, BossTrail, BossDecoys, BossDecoyPop, BossLighting, BossUltimate, BossCall, BossRecover, BossDamage, BossHazardEnd, BossMineGone, BossPhase, BossDefeated, BossEscaped, BossCleared, BossReward, Telegraph, Impact`.
Формы: `FormStart, FormEnd, FormSmash, FormBlast, FormAttack, FormZap, FormPull`.
События/баффы: `EventWarn, EventStrike, EventImpact, EventEnd, Rift, Combo, MutagenFull, BuffStart, BuffTick, BuffPull, BuffEnd, Roulette`.
Мутации: `MutCast, MutImpact, MutTick, MutPet`. База: `PetCollected, ZoneUnlocked, RaidOpenFort`.
