# GitHub - libGDX gdx-ai

**Repository:** https://github.com/libgdx/gdx-ai

## Назначение
Библиотека AI-компонентов для экосистемы libGDX. Используйте как источник реализации классических игровых AI-паттернов.

## Что исследовать
- Steering Behaviors.
- Pathfinding.
- Behavior Trees.
- State Machines.
- Formation motion.

## Учебный план
1. Прочитать README и package structure.
2. Найти минимальный steering example.
3. Проследить, как агент получает desired velocity.
4. Найти pathfinding API и пример графа.
5. Сравнить интерфейсы с реализацией в выбранном движке.

## Проверка
Перед использованием проверить актуальность проекта, release, совместимость с вашей версией libGDX и LICENSE.
