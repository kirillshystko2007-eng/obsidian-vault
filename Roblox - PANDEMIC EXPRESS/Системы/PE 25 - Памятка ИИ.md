# Памятка следующему ИИ
Связано: [[PE 00 - Обзор]], [[PE 01 - Архитектура и слои]], [[PE 04 - Сетевые контракты]], [[PE 26 - Очередь аудита]].

> Перед работой прочитай [[PE 27 - Дополнения и риски]]: бэкдор-плагин, эксплойт `Workspace.Revolver`, PrimaryPart=Head при телепорте.

1. Начни с [[PE 00 - Обзор]] и конкретной системы; затем проверь актуальный Roblox Studio DataModel, снимок может устареть.
2. Читай активную версию целиком до edit; grep по всем scripts находит backup clones.
3. Для каждой механики проследи обе стороны remote и все изменяемые attributes/Bindable API.
4. Урон, Cash, kill credit, выдача Tool и teleport остаются серверно авторитетными.
5. Сверяй Workspace instance, ServerStorage template и runtime clone. У многих функций есть вложенные Tool/NPC scripts.
6. Учитывай R6 assumptions, имена rig/attachments/KeyframeSequence, Backpack/Character transitions.
7. Большую карту модифицируй участками, не bulk-edit всего Workspace.
8. Не публикуй плейс и не делай несвязанных изменений. Runtime-тестировать только если это запрошено/входит в задачу; ограничение проверки сообщать честно.

Система содержит две версии цикла времени; travel markers требуют tag/attributes; DataStore в Studio может быть выключен. Сначала сверяй [[PE 26 - Очередь аудита]]. Граф — документация, не гарантированный источник live state.
