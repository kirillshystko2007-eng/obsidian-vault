# MM 29 — Сложность: Обычный и Хард (0.8.10)

Для режима **«Истинная природа»** (только там есть апокалипсис) в меню появился переключатель **ОБЫЧНЫЙ / ХАРД**. → [[MM 26 - Апокалипсис 3 фазы]], [[MM 18 - История версий]]

| | Обычный (по умолчанию) | Хард |
|---|---|---|
| Метеориты, фазы 1–2 | **вдвое меньше** | как было в 0.8.9 (полный метеоритный дождь) |
| Фаза 3 (перестройка, 300 кристаллов) | метеоритов нет | метеоритов нет |
| Остальное | без изменений | без изменений |

> Хард = игра такой, какой она была до 0.8.10. Метеориты в 3-й фазе не падали и раньше (`startRebuild` чистит их, а `Meteors.update` получает интенсивность 0), поэтому в обоих уровнях они с перестройкой прекращаются.

## Как сделано
- `Save.hard` (0/1, по умолчанию 0 = Обычный; старые сохранения тоже станут Обычным).
- В начале заезда `resetRun()` фиксирует `run.hard` и `Meteors.rate` = 1 (Хард) или 0.5 (Обычный); переключение в меню на текущий заезд не влияет.
- `Meteors.update`: таймер появления идёт со скоростью `(0.35 + lvl·1.2) · rate`. Значит, меньше и горящих камней на дороге.
- Меню: кнопка `#bDiff` в `#mDiff` под кнопками режимов (стиль как у RU/EN), видна только при «Истинной природе»; к описанию режима добавляется строка `descNormal`/`descHard`.
- Рекорды пока общие для обеих сложностей.

## Проверка (WebView2, без звука)
За 60 с каждой фазы на 180 км/ч: Обычный — фаза 1: **12** метеоритов, фаза 2: **44**, фаза 3: **0**; Хард — **26**, **90**, **0**. Ошибок в консоли нет.
