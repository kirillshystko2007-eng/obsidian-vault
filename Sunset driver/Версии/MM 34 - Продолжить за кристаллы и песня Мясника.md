# MM 34 — «Продолжить» за кристаллы и песня Мясника (0.8.14)

Запрос пользователя. → [[MM 18 - История версий]], [[MM 33 - Улучшения и добавления 0.8.13]]

## Продолжить за кристаллы
- После **каждой** аварии в гонке (Старая эра, Истинная природа, Новая эра) экран проигрыша показывает кнопку **«ПРОДОЛЖИТЬ · N ◆»**. Платишь ◆ из кошелька — заезд идёт дальше с того же места (очки, км, фаза сохраняются; комбо сбрасывается).
- Цена **удваивается** с каждым продолжением в заезде: Обычный 25 → 50 → 100 → 200…, Хард вдвое дороже (50 → 100 → 200…). Новый заезд — снова с начала.
- Не хватает ◆ — кнопка серая: «ПРОДОЛЖИТЬ · НУЖНО N ◆».
- Заменяет из 0.8.13: автоматический щит Обычного (−25 кристаллов заезда) и «второй шанс» один раз за 50 ◆.
- Код: `REVIVE = 25`, `contCost()`, `run.conts`, `revive()`.

## Песня Мясника в овердрайве (только для разработчика)
- Скин **Мясник** (dev) + включён режим разработчика → в овердрайве играет только **Scattle — To the Top** (`music/dev/dev-to-the-top.mp3`), по кругу, с места, где остановилась. Играет даже при выключенном радио (если музыка включена). Цвет овердрайва `0xff2a6d`.
- Других скинов это не касается: у них прежняя ротация od-песен.
- Код: запись `'dev'` в `RADIO`, `DEV_OD`, `devOd()`.
- ⚠️ Песня **не CC0** (саундтрек Hotline Miami) — нет в `licenses.txt`. Публичные сборки без `music/dev/`.
