# VM 03 — Как снимать

Назад: [[VM 00 - Визуальная память]] · уроки: [[VM 01 - Уроки]]

## Общие правила
- Звук в тестах всегда выключен.
- На каждый эффект 3 кадра: **подготовка** (замах/сбор), **пик** (момент удара), **после** (затухание, след). Для быстрых эффектов — видео.
- Один и тот же ракурс «до» и «после» исправления.
- Имя файла: `ГГГГ-ММ-ДД ПРОЕКТ NN что.jpg` в `img/`.
- Временные копии, тестовые объекты и подменённые настройки после съёмки убрать.

## Roblox Studio (MCP)
- `screen_capture` в Edit: можно задать `camera_position` / `look_at_position`.
- В **Play** параметры камеры игнорируются — снимается камера игрока. `CameraType = Scriptable` на клиенте перебивается камерным скриптом игры. Решение: на клиенте `RunService:BindToRenderStep("VMCam", Enum.RenderPriority.Camera.Value + 1, ...)` и в нём каждый кадр ставить `camera.CFrame`; после съёмки `UnbindFromRenderStep` и вернуть `CameraType`.
- Тайминг: способность запускать с сервера через `task.spawn`, затем `task.wait(задержка до пика)` и сразу `screen_capture`. Для серии кадров — `video_capture`.
- Звук: на клиенте все `Sound` перевести в `SoundGroup` с `Volume = 0` (MasterVolume из плагина недоступен).
- Файлы кадров MCP сохраняет в папку tool-results сессии — оттуда копировать в `img/`.

## three.js / веб (Playwright)
- Headless-скриншоты страницы с отключённым звуком (`vMaster 0` в Mono Moto). Для анимаций — несколько кадров с фиксированным шагом времени.

## Окно приложения Windows
- Только окно нужной программы через `PrintWindow` (PowerShell + user32) — не снимать весь рабочий стол, там может быть личное.

## Blender
- Рендер превью через сокет аддона (127.0.0.1:9876) — скрипт render.py.
