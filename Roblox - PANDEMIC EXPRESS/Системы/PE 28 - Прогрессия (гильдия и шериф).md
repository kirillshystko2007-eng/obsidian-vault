## Суть
| | **Guild** (FRONTIER GUILD) | **Sheriff** (Sheriff's Office) |
|---|---|---|
| Работа | монстры, разведка, лут | бандиты, убийцы, порядок в городе |
| Листовка | CONTRACT | WARRANT / WANTED (именные главари — DEAD OR ALIVE) / пропавший |
| Ранги (по 5 уровней) | Tin → Bronze (6) → Silver (11) → Gold (16) | Tin Star → Bronze Star → Silver Star → Gold Star |
| Доска | `BoardBack` в таверне (8 мест) | `Workspace.SheriffBoard` на стене тюрьмы (6 мест) |
| Кто подписывает | `Workspace.Guildquester` | `Workspace.Sheriff` |

20 уровней на трек (`MAX_LEVEL`), опыт только из контрактов, **каждый уровень — награда, которую нужно забрать** в журнале.

## Как берётся контракт
1. Листовка висит на доске → **E** → в руке появляется предмет `Flyer` (id для сохранения `Flyer:<questId>`).
2. ЛКМ с листовкой в руке — прочитать крупно, видны шансы на подпись.
3. Показать выдающему (промпт **Talk**). Он читает `REVIEW_TIME = 2.6` с и ставит штамп:
   - уровень входа ≤ уровень игрока + 1 → **APPROVED** всегда;
   - выше — шанс падает на 20 % за уровень (`Catalog.approvalChance`); перк гильдии `GuildTrust` даёт +10 %;
   - **REFUSED** — листовка остаётся, контракт закрыт на `DENY_COOLDOWN = 120` с.
4. Одновременно до `MAX_ACTIVE = 3` контрактов (перк `ExtraContract` — ещё один). Доска обновляется раз в `BOARD_ROTATE = 600` с. Повтор контракта платит меньше: `REPEAT_FACTORS = 1 / 0.75 / 0.5`.
5. Выполнил → снова Talk → выплата (опыт + деньги).

Разговор с выдающим по порядку: выплатить готовое → прочитать листовку в руке → иначе открыть журнал.

## Что считается
| Тип цели | Откуда приходит |
|---|---|
| `kill` (вид `Kind`, опц. зона, опц. только ночью, опц. `boss`) | `ServerStorage.KillFeed` ← `KillTracker` |
| `loot` | `ServerStorage.LootFeed` ← `LootService` |
| `visit` (число мест или список зон) | сервис сам опрашивает положение игрока |

Монстр засчитывается, только если у модели есть атрибут **`Kind`** и тег **`Hostile`**; главарь — атрибут `BossName`. Вид `Monster` = любой из `MonsterKinds` (Zombie, Werewolf, Vampire, Chupacabra, Skinwalker). Вид `Wanted` = игрок с атрибутом `Wanted` (убийца в городе; `PvPRules` не начисляет за него вину).

## Звезда помощника
Первая подписанная бумага шерифа = присяга: игрок носит звезду. Клавиша **B** — звезда показывает направление на цель активного ордера и «теплеет» рядом с бандитами (перк). Лагеря для компаса — невидимые части с тегом `HostileCamp` (ставит `BanditDirector`).

> [!warning] Конфликт клавиши B
> На B также открывается колесо эмоций и доставания ([[PE 34 - Эмоции, колесо B и доставание револьвера]]). У присягнувшего игрока срабатывает и то и другое.

| Что | Путь |

Атрибут игрока `MenuOpen` освобождает курсор, пока открыт журнал.

## При правке
- Новый контракт = запись в `Quests`; новый вид врага = `Kinds` + `Habitats` + атрибут `Kind` и тег `Hostile` на модели, иначе убийства не считаются.
- Ничего не трогается до `DataLoaded` (иначе затрётся сохранённый прогресс).
- Промпты **не срабатывают от ввода MCP** — проверять через `ProgressionDebug`.
