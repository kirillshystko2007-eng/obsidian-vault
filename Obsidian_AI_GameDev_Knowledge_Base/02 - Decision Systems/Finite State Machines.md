# Finite State Machines (FSM) / Конечные автоматы

FSM описывает агента как конечный набор состояний и переходов между ними.

## Термины
- State: Patrol, Investigate, Chase, Attack, Flee.
- Transition: условие перехода.
- Entry/Exit action: действия при входе/выходе.
- Guard: логическое условие перехода.

## Пример
Patrol → Investigate, если услышан шум.
Investigate → Chase, если игрок подтверждён визуально.
Chase → Attack, если цель в радиусе атаки.
Chase → Search, если потеряна видимость.
Search → Patrol, если таймер истёк.

## Плюсы
Простота, предсказуемость, удобная визуализация и низкая вычислительная стоимость.

## Минусы
Рост числа переходов, сложность комбинации независимых состояний, риск «спагетти»-логики.

## Варианты
- Hierarchical FSM: вложенные состояния.
- Pushdown Automaton: стек состояний, полезен для временных режимов.
- Concurrent FSM: несколько параллельных машин для независимых аспектов.

## Практика
Реализуйте патрульного NPC; добавьте interruptible attack, cooldown и потерю цели. Покройте каждый переход тестом.
