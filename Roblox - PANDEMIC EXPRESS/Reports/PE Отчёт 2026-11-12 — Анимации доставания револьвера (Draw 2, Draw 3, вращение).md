# PE Отчёт 2026-11-12 — Анимации доставания револьвера (Draw 2, Draw 3, вращение)

Журнал: [[PE Отчёты — журнал]] · системы: [[PE 08 - Револьвер]], [[PE 07 - Анимации]], [[PE 09 - Dual stance]] · хаб: [[PE 00 - Обзор]]

Вне дорожной карты (полировка револьвера). Пять просьб пользователя за один день:
1. «i just made revolverequip2 and i want to play it when equiped… b key where poses menu upper emotes lower action animations»
2. «make this animation better and make the revolver spin in player hand while he draws a gun»
3. «make a new animation based on this video and put it in the new slot» (запись OBS: аниме-сцена, пистолет появляется в раскрытой ладони)
4. «make less visual effects»
5. «make better quality and some sparkles»

## Что теперь есть в игре
Игрок выбирает, **как персонаж достаёт револьвер**, в колесе на **B**: верхняя половина — EMOTES (Sit), нижняя — **ACTIONS**. Активный вариант подсвечен красным; если револьвер уже в руке, выбранный вариант сразу проигрывается.

| Слот | Клип | Что происходит |
|---|---|---|
| Draw 1 | `Revolverdraw` | старое доставание, без изменений |
| **Draw 2** (по умолчанию) | `Revolverequip2` | рука к кобуре → рывок вверх, револьвер **делает 2 оборота на пальце** → поймал, ствол вперёд → стойка |
| **Draw 3** | `Revolverequip3` | по видео: рука складывается через грудь → выбрасывается в сторону с пустой ладонью → **револьвер появляется в руке** (звёздный блик + искры) и делает 3 оборота → поймал → опускает к бедру → стойка |

Двойные револьверы (Stance 2) по-прежнему используют `Dualrevolverdraw`.

## Что сделано (пути DataModel)

### 1. Выбор анимации и колесо B
- `ReplicatedStorage.Animations.Revolverequip2` — копия анимации пользователя из `ServerStorage.RBX_ANIMSAVES.Dummy1.revolverequip2` (оригинал не тронут).
- `ServerStorage.Revolver.RevolverAnimation` → `playDraw()` берёт клип из атрибута игрока **`RevolverEquipAnim`** (имя KeyframeSequence); пока атрибут пуст — `DEFAULT_EQUIP_ANIM = "Revolverequip2"`. Смена атрибута при револьвере в руке = повторное доставание.
- `StarterPlayerScripts.EmoteWheel` — колесо поделено пополам: `EMOTES` (верх) и новая таблица **`ACTIONS`** (низ): `{ name, attr = "RevolverEquipAnim", value = <клип>, icon, default }`. Подписи половин EMOTES / ACTIONS, центр — «POSES».
- `StarterPlayerScripts.CharacterAnimator` → `ARM_LAYERS` += `Revolverequip2`, `Revolverequip3` (иначе CharacterAnimator глушит чужие треки).

### 2. Draw 2 улучшен + вращение
Что было не так в исходном клипе (1.0 с): рука прыгала к кобуре за 0.1 с и **0.7 с стояла**; финальный подъём почти не был виден, потому что стойка `Revolveridle2` начинает вливаться за 0.4 с до конца клипа; все ключи Linear.

Новый клип собран скриптом **из тех же ключевых поз пользователя** (1.30 с, Cubic):

| t, с | Поза |
|---|---|
| 0.15 | быстрый выход руки к кобуре |
| 0.27 | кисть сжимает рукоять, чуть проседает |
| 0.47 | вырывает револьвер (с 0.30 он крутится) |
| 0.68 | мах чуть выше уровня |
| 0.86 | ловит, ствол вперёд |
| 0.93 | короткая отдача от ловли |
| 1.30 | приходит **ровно в позу `Revolveridle2`**, поэтому переход в стойку ничего не съедает |

Левая рука — исходный противовес пользователя, сглажен и возвращается в ноль.

**Вращение** — новый модуль **`ReplicatedStorage.RevolverSpin`** (клиент). Револьвер держится штатным сварным швом `RightGrip` (**Weld**, не Motor6D), поэтому модуль каждый кадр поворачивает его `C1` вокруг точки `PIVOT = (0.2, 0.55, 0)` — скоба спускового крючка в координатах `Handle`. Целое число оборотов → револьвер возвращается точно в хват. Выстрел, прицеливание и убирание оружия во время вращения дозавершают текущий оборот за ~0.1 с (`CANCEL_RATE`).

Чтобы вращение видели другие игроки: `RemoteEvent ReplicatedStorage.RevolverDrawSpin` → `ServerScriptService.RevolverSpinRelay` (проверка: в руках Tool «Revolver», не чаще раза в 0.3 с, имя клипа — строка) → `StarterPlayerScripts.RevolverSpinClient` запускает тот же модуль на чужом персонаже.

### 3. Draw 3 по видео
Запись разобрана по кадрам (10 к/с на участке появления пистолета). Клип `Revolverequip3`, 1.85 с:

| t, с | Поза (по кадрам видео) |
|---|---|
| 0.16–0.25 | замах: правая рука сложена через грудь, кисть у дальнего плеча |
| 0.39–0.50 | выброс руки в сторону с перелётом и возвратом; **револьвер ещё невидим** |
| 0.46 | револьвер появляется в ладони, 3 оборота до 1.02 |
| 1.02–1.12 | поймал, короткая отдача |
| 1.36–1.50 | револьвер внизу у бедра, ствол вниз-вперёд (финальный кадр сцены) |
| 1.85 | поза `Revolveridle2` |

- Позы R6-руки заданы не «на глаз» в осях сустава, а функцией `armPose(C0, C1, dir, front, shift)`: «рука смотрит вдоль `dir` в координатах торса» → `Transform = C0⁻¹ · armCF · C1`. Ствол револьвера идёт вдоль руки.
- У клипа свой короткий вход `blend = 0.15` с (общий `DRAW_BLEND = 0.45` с размывал быстрый замах).
- `RevolverSpin` стал **настраиваемым по клипам**: `M.CLIPS[имя] = { start, finish, turns, appear?, blend? }`. `appear` — до этого момента детали револьвера локально прозрачны, потом появляются с эффектом. Прерывание (выстрел / убрал оружие) сразу возвращает видимость.
- Нажатие на спуск и выстрел из конца видео **не** включены: это стрельба, а не доставание.

### 4–5. Эффект появления
Сначала были две большие неоновые вспышки (золотая и фиолетовая) — по просьбе убавлены до одной маленькой, затем заменены на частицы (качественнее и мельче):
- **Glint** — одна мягкая звезда-блик, 0.28 с;
- **Burst** — 12 искр разлетаются, тормозят и опадают;
- **Trail** — редкие искры (14/с) сыплются с вращающегося револьвера до ловли;
- слабый тёплый свет 0.3 с.

Всё висит на `Attachment` в точке скобы, поэтому едет вместе с рукой; через 1 с после ловли убирается. Цвет один — тёплое золото `FX_COLOR`.

## Настройка (верх `ReplicatedStorage.RevolverSpin`)
| Параметр | Что делает |
|---|---|
| `CLIPS[...].turns / start / finish` | число оборотов и окно вращения в секундах клипа |
| `CLIPS[...].appear` | момент появления револьвера (убрать поле — револьвер виден сразу) |
| `DIRECTION` | `-1` — крутить в другую сторону |
| `PIVOT` | точка вращения; подобрана по одному стоп-кадру, сдвинуть, если револьвер «облетает» кисть |
| `FLASH_SIZE`, `FLASH_LIGHT`, `SPARKLES`, `SPARKLE_TRAIL` | блик, свет, число искр, искры в секунду; `0` выключает каждую часть |

Добавить ещё одно доставание: положить KeyframeSequence в `ReplicatedStorage.Animations`, дописать строку в `ACTIONS` (EmoteWheel), имя в `ARM_LAYERS` (CharacterAnimator) и, если нужно вращение, запись в `RevolverSpin.CLIPS`. В колесе осталось 1 свободное место в нижней половине.

## Известные ограничения
- Выбор варианта живёт **только в текущей сессии** (атрибут клиента, не сохраняется в PlayerData).
- **Клавиша B занята дважды**: колесо и звезда помощника шерифа в `ProgressionClient` (`STAR_KEY`). У присягнувшего игрока B делает оба действия.
- Для живых серверов клипы нужно опубликовать (AnimationId), как и остальные анимации — см. [[PE 27 - Дополнения и риски]].
- У R6 нет пальцев и локтя: «раскрытая ладонь» из видео передана позой руки и эффектом.
- Вращение и эффект — чисто визуальные, на клиенте; на попадания и урон не влияют.

Быстрый откат без возврата скриптов: `DEFAULT_EQUIP_ANIM = "Revolverdraw"` и убрать строки Draw 2 / Draw 3 из `ACTIONS`. Полный откат вращения: удалить `RevolverSpin`, `RevolverDrawSpin`, `RevolverSpinRelay`, `RevolverSpinClient` и вернуть `RevolverAnimation` из backup.

**Плейс не сохранён** (как обычно — сохраняет пользователь).
