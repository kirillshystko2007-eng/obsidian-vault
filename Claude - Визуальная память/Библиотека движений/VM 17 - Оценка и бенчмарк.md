## Критические дефекты
Критический дефект **нельзя компенсировать** баллами за другое:
- неправильный или несовместимый риг;
- сломанные суставы или невозможные позы;
- непреднамеренное скольжение стоп там, где стопа должна стоять;
- потеря контакта с предметом в ключевой фазе взаимодействия;
- резкий скачок в бесшовном цикле;
- ломающийся переход между состояниями;
- опубликованная анимация не подходит целевому персонажу.

## Чек-лист Animation Critic
- [ ] Действие понятно без объяснения.
- [ ] Ключевые позы читаются с игровой камеры.
- [ ] Тайминг соответствует намерению.
- [ ] Spacing создаёт нужное ускорение.
- [ ] Масса и импульс убедительны.
- [ ] Центр масс и баланс согласованы.
- [ ] Дуги движения выглядят намеренными.
- [ ] Вторичные движения поддерживают основное действие.
- [ ] Контакты и опора убедительны.
- [ ] Переходы не обрывают движение.
- [ ] Анимация технически совместима с ригом.
- [ ] Визуальная проверка действительно выполнена — или явно отмечена как невыполненная.

## Benchmark: 10 контрольных заданий
Для сравнения качества разных версий Claude и конфигураций Skills:
1. Естественный R15 Idle с бесшовным циклом.
2. Casual Walk без скольжения стоп.
3. Heavy Walk с убедительной массой.
4. Sprint с правильной координацией рук и ног.
5. Jump с anticipation и landing.
6. Hard Landing с поглощением нагрузки.
7. Heavy Greatsword Attack.
8. Parry → Counterattack.
9. Hit Reaction разной интенсивности.
10. Плавный переход Run → Idle.

Для каждого теста сохранять: Motion Blueprint; выбранные референсы и их лицензии; целевой риг; исходные анимационные данные; скриншоты или видео результата; оценку по критериям; найденные дефекты; исправленную версию; статус визуальной проверки.

**Не отмечать тест пройденным только потому, что код сгенерирован или скрипт не выдал ошибку.**
