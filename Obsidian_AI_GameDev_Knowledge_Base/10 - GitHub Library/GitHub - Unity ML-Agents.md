# GitHub - Unity ML-Agents

**Repository:** https://github.com/Unity-Technologies/ml-agents  
**Maintainer:** Unity Technologies  
**Назначение:** toolkit для использования игр и симуляций как сред обучения интеллектуальных агентов.

## Что подтверждено в репозитории/документации
- Deep Reinforcement Learning и Imitation Learning.
- Примеры сред и документация.
- PPO и SAC.
- Behavioral Cloning и GAIL.
- Self-play и multi-agent сценарии.
- Curriculum learning и environment randomization.
- Python API для взаимодействия со средой.
