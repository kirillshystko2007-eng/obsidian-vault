# ZS 04 — Данные и сохранение

Связано: [[ZS 00 - Обзор]] · [[ZS 01 - Архитектура и сеть]] · [[ZS 06 - Риски и очередь аудита]]

`ServerScriptService.Services.DataService` (569 строк).

| | |
|---|---|
| DataStore | `HordeHatch_PlayerData` (`Config.Data.StoreName`) |
| Автосейв | каждые 120 с + при выходе + `BindToClose` |
| Схема | `SCHEMA_VERSION = 5`; старые v1/v2 мигрируются, данные сверяются с `DEFAULTS` |
| Запись | `UpdateAsync`, который **не понижает** данные, записанные более новой схемой |
| Ошибка загрузки | игрок получает временные значения по умолчанию, **сохранение на сессию выключается**, чтобы неудачная загрузка не затёрла настоящие данные |
| Клиент | получает только вид для чтения через `ProfileSync` и ничего не отправляет обратно |
| Межсерверный замок сессии | **нет** (ограничение записано в шапке модуля) |

## Поля профиля (`DEFAULTS`)

- **Валюты и уровень:** `Coins, Gems, XP, Level, TutorialDone, SelectedMap ("City"), LastDaily`
- **Забеги:** `BossesBeaten {[mapId]=раз}`, `Boosts {Horde, Shield, Coin}`
- **Stats:** Runs, Finishes, BestDistance, CoinsEarned, Hatches, RobotsDestroyed, BossesDefeated, BestHorde, GemsEarned, Infected, Transformations, Fusions, EventsSurvived, BestCombo, RiftsFound, Juggernauts, NinjaClans, BarrelsBlown, BestScore, BestTime
- **Upgrades:** StartHorde, Capacity, CoinBonus, Shield, PenSlots, Claws, Sprint
- **Питомцы:** `Companions {[uid]={Id, Got}}`, `NextUid`, `Discovered`, `Equipped {uid…}`, `Placed {["slot"]=uid}` (слоты 1–8 = база 1, 9+ = базы 2–6), `BaseZones` (1–6), `Storage`
- **v4:** `Forms {[id]={Level}}`, `FusionsFound`, `FormEquipped`, `Gland`, `Achievements`, `Daily {Day, Missions}`, косметика
- **Другие сервисы:** `Wardrobe {Owned, Hero, Horde}`, `MutPowers {Owned {[id]={R,L,Dna}}, Equipped}`, ресурсы и данные Fort

Атрибуты игрока, которые видят клиенты: `Plot, Horde, InRun, EquippedIds, HeroOutfit, HordeOutfit, MutLook, MutSlot1..3, Form/FormEnds/FormMax, Buff_<id>/BuffMax_<id>, LabMutation, Zombie, Intro`.

В Studio тестовые выдачи (`DebugRaid`) сначала вызывают `DataService.DisableSaving`, чтобы не попасть в настоящее сохранение.
