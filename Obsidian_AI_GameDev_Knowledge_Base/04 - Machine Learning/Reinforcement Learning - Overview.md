# Reinforcement Learning (RL) / Обучение с подкреплением

RL изучает, как агент выбирает действия в среде, чтобы максимизировать ожидаемую сумму наград.

## Формальная модель
Часто задаётся через Markov Decision Process (MDP): states S, actions A, transition dynamics P, reward R, discount γ.

## Цикл
1. Agent получает observation.
2. Policy выбирает action.
3. Environment возвращает next observation и reward.
4. Опыт используется для обновления policy/value.
5. Повторение по эпизодам или шагам.

## Термины
- Policy: стратегия выбора действия.
- Reward: численный сигнал цели.
- Return: накопленная дисконтированная награда.
- Episode: последовательность до terminal state.
- Exploration/exploitation: исследование/использование знаний.
- Observation vs state: агент не всегда видит полное состояние.

## Алгоритмы
PPO — популярный on-policy метод.
SAC — off-policy actor-critic, обычно для непрерывных действий.
DQN — value-based метод для дискретных действий.
Алгоритмы отличаются предположениями, эффективностью данных и сложностью настройки.

## Reward design
Плохо заданная награда вызывает reward hacking: агент максимизирует метрику, но не желаемое поведение. Нужны тестовые сценарии, визуализация траекторий и анализ побочных стратегий.

## Практика
Начните с простой среды: агент перемещается к цели и избегает падения. Затем добавьте препятствия и несколько агентов.
