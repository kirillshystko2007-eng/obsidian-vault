# Файлы и сборка
Часть [[MM 00 - Обзор]].

| Файл | Что это |
|---|---|
| `index.html` | Всё сразу: CSS, 10 шрифтов (Handjet, Pixelify Sans) в base64, three.js r128 (одна строка 603 КБ), код игры (стр. 291–2672), QR-генератор Kazuhiko Arase, PWA-подсказки |
| `sw.js` | Service worker: cache-first; имя кэша `mono-moto-22912d09ac` меняется с каждой сборкой, старый кэш удаляется |
| `manifest.webmanifest` | PWA: standalone/fullscreen, тёмная тема `#0d0d0f`, иконки 192/512 (+maskable) |
| `licenses.txt` | MIT (three.js, QR), SIL OFL 1.1 (шрифты) |
| `icon-*.png`, `apple-touch-icon.png` | Иконки |

## Хвост страницы (стр. 2680–2745)
- iOS не в режиме standalone → подсказка «Поделиться → На экран „Домой“».
- Десктоп → QR-код с адресом страницы, чтобы открыть игру на телефоне.
- `sw.js` регистрируется только на https/localhost.

## Платформы
- Браузер/PWA, плюс хуки **Capacitor** (кнопка «назад» на Android, pause/resume), см. [[MM 03 - Состояния игры]].
- Хук `window.claude.hot` — горячая перезагрузка с сохранением рекорда, см. [[MM 16 - Отладка]].

## Обновлено в 0.6–0.7
