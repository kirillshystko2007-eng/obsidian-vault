# G7.1 — Матрица проверки маршрута и мира

Подзадача: [[PE_Goals_70_Acceptance]]. Это план проверки, а не результат фактического тестирования.

| Сценарий | Ожидаемый результат |
|---|---|
| Обойти все здания первой локации | Каждый объект в реестре пройден, нет недоступных критичных дверей/лестниц. |
| Пройти второй остров от станции до края и назад | Проходимые маршруты, отмеченные города/природа/POI, нет непреднамеренной пустоты. |
| Train1 проходит прямой/поворотный/обратный маршрут | Высота и направление совпадают с route, нет столкновений/рывков. |
| Рельсы работают длительно | Запас впереди стабилен, хвост удаляется, число Instances не растёт бесконечно. |
| Один пассажир садится/выходит | Переход в Train2, seat и arrival position корректны. |
| Группа заполняет capacity | Последний слот работает, следующий игрок получает ясный отказ, пассажиры синхронно прибывают. |
| Игрок опоздал / повторно нажал prompt | Нет дублирования сессии и неожиданного teleport. |
| Пассажир умер / вышел / reset во время поездки | Slot освобождён, остальные продолжают, новая модель не перемещается старым callback. |
| Поезд/маркер/сессия отменена | Все пассажиры возвращены в безопасную точку, constraints и UI очищены. |
| Остановка и обратный рейс | Правильная станция/направление, повторная посадка работает. |
| First/second island streaming и ночная фаза | Нет отсутствующей геометрии, критичных видимых швов или тёмной нечитаемой посадки. |

Зафиксировать версии Studio/place, число игроков, результат/ошибки/снимки и статус блокера. Только реально выполненный Play test позволяет перевести критерий в `done`.
