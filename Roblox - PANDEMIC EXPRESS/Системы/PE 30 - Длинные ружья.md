# Длинные ружья: Double Barrel и Winchester
Связано: [[PE 07 - Анимации]], [[PE 08 - Револьвер]], [[PE 11 - Урон и киллы]], [[PE 14 - Арсенал]], [[PE 29 - Боевые приёмы (толчок и уворот)]], [[PE 32 - Бандиты]] · отчёт: [[PE Отчёт 2026-11-11 — Толчок, уворот, ружья, монстры, бандиты]]

Общая система двуручного оружия. Сделана 2026-11-11 и заменила прежний отдельный скрипт Winchester из [[PE 27 - Дополнения и риски]].

## Два ружья
| | **Double Barrel** | **Winchester '73** |
|---|---|---|
| Тип | переломка (`kind = "break"`) | рычажная (`kind = "lever"`) |
| Патронов | 2 | 15 |
| Выстрел | 9 дробин × 12 урона, разброс 4.6° | 1 пуля × 60 урона, без разброса |
| Дальность | 95, урон падает с 28 студов до 35 % | 400, без падения |
| Голова (игроки) | ×1.5 | ×2 |
| Темп | 0.32 с между стволами | 0.85 с (после выстрела — ход рычага, вылетает гильза) |
| Перезарядка | **R** или пусто: переломить, два патрона, закрыть — 1.75 с | **R**: по одному патрону каждые 0.45 с, клик останавливает |
| Клипы (префикс) | `DB`: Idle, Aim, Fire, Equip, Reload, Butt | `WR`: Idle, Aim, Fire, Equip, Lever, Load, Butt |
| Откуда модель | риг пользователя (оригинал в `_MapBackup.Doublebarrel_model_2026-11-11`) | прежняя модель из `_AnimBackup` |

По NPC урон идёт через `HitZones` (голова — убийство), по игрокам — множитель головы и `PvPRules`.

## Как устроено
**Ружьё — часть рига персонажа.** При экипировке сервер заменяет шов `RightGrip` на **Motor6D `GunGrip`** (Right Arm → Handle), поэтому клипы `DB*`/`WR*` двигают ружьё вместе с руками, а подвижные части (шарнир стволов `Barrels`, патроны `Shells`, рычаг) — тоже кадры анимации. Персонаж получает атрибут **`LongGun = true`**:
- HUD оставляет видимой поддерживающую руку;
- `ArmAttachFix` не трогает руки;
- `LongGunPoseClient` наклоняет ружьё за взглядом.

**Позы решаются, а не набиваются вручную.** У R6 руки не гнутся, поэтому `GunAnim` получает «где ружьё и за что держится каждая рука» и сам находит повороты плеч и позу шва ружья. Корпус стоит боком (торс вправо, голова назад) — только так обе руки R6 достают.

**Наклон за взглядом.** `LongGunPoseClient` каждый кадр поворачивает оба плеча как одно целое: локальный игрок — по камере, остальные — по атрибуту персонажа `AimPitch`, который `LongGunAimService` получает несколько раз в секунду. В первом лице при прицеливании ружьё дополнительно сдвигается так, чтобы линия прицела была под центром экрана.

**Выстрел.** Клиент шлёт `fire` с лучом камеры. Сервер владеет патронами (атрибут Tool `Ammo`), пускает каждую дробину от дула к перекрестию, наносит урон, ставит метку для `KillTracker`, шлёт хит-маркер и говорит остальным клиентам нарисовать трассеры и сыграть звук.

## Где что лежит
| Что | Путь |
|---|---|
| Клиентская половина | `ReplicatedStorage.LongGun` — в каждом ружье крошечный LocalScript `LongGunClient`: `require(ReplicatedStorage.LongGun).run(script.Parent)` |
| Серверная половина | `ServerStorage.LongGunCore` — Script `LongGunServer`: `require(ServerStorage.LongGunCore).serve(script.Parent)`; `Core.attach(character, tool)` даёт тот же риг NPC (бандитам) |
| Настройки ружья | модуль `GunConfig` внутри Tool, исходники — `ServerStorage.LongGunParts.DoubleBarrelConfig` / `WinchesterConfig` |
| Сборка Tool | `ServerStorage.LongGunBuilder`: `B.doubleBarrel()`, `B.winchester()`, `B.displays()` (обновляет экземпляры-пикапы в Workspace) |
| Клипы | `ServerStorage.GunAnim` → `build()` переписывает `DB*` / `WR*` |
| Наклон | `StarterPlayerScripts.LongGunPoseClient`, `ServerScriptService.LongGunAimService` |
| Remote | `GunRemote` внутри каждого Tool |
| Шаблоны | `ServerStorage.ItemTemplates["Double Barrel"]`, `["Winchester Rifle"]`; в мире — `Workspace["Double Barrel"]`, `Workspace["Winchester Rifle"]` |

Каждый Tool несёт атрибут `GripC1` (канонический хват в координатах Handle) и attachment дула со вспышкой.

## Как получить в игре
Пикапы в мире (возвращаются через `PickupRespawner`), награды гильдии (Winchester — уровень 10, Double Barrel — уровень 15, см. [[PE 28 - Прогрессия (гильдия и шериф)]]). Сохраняются в сумке через `ItemRegistry`.

## При правке
- Поменял геометрию или конфиг → пересобрать Tool (`LongGunBuilder`) **и** клипы (`GunAnim`), иначе руки не попадут на ружьё.
- Скрипты из бесплатных моделей имели `Sandboxed = true` и не видели новые модули — должно быть `false`.
- Третье ружьё = ещё один конфиг в `LongGunParts` + функция в `LongGunBuilder` + набор клипов с новым префиксом.
