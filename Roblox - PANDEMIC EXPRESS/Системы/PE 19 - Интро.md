# Интро и сохранение просмотра
Связано: [[PE 04 - Сетевые контракты]], [[PE 03 - Клиентские контроллеры]], [[PE 20 - HUD]].

Раннее покрытие экрана: `ReplicatedFirst.IntroCover`. Клиентский `StarterPlayerScripts.IntroClient` использует `ReplicatedStorage.IntroRemotes.IntroEvent` и модули `IntroSceneBuilder`, `IntroUI`, `IntroChoreo`, `IntroDetail`. Серверный `IntroService` создаёт IntroEvent, если отсутствует, решает надо ли играть intro, использует DataStore для отметки просмотра. Client отправляет `RequestState`, `Begin`, `Finished`; server отправляет `State`.

IntroClient помечает GUI атрибутом `Claimed`, чтобы ранний cover не конфликтовал с cinematic UI. Скрипт взаимодействует с Lighting, SoundService, StarterGui, TweenService и UserInputService.

Для теста различать Studio режим «играть интро каждый раз» и production first-join/returning-user. DataStore API может быть выключен в Studio; сервис содержит retry/pcall. Проверять ввод пропуска, смерть/respawn в cutscene, late-loading и звуки с пустым ID. Runtime не проверялся. См. [[PE 04 - Сетевые контракты]] и [[PE 20 - HUD]].
