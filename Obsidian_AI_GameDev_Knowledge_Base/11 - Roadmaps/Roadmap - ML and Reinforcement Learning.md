- [ ] Python basics.

## RL path
- [ ] Понять MDP, policy, reward, return.
- [ ] Создать простую tabular RL среду.
- [ ] Изучить DQN на дискретном action space.
- [ ] Изучить PPO.
- [ ] Изучить SAC для continuous control.
- [ ] Изучить reward shaping и reward hacking.
- [ ] Запустить пример [[GitHub - Unity ML-Agents]].
- [ ] Создать собственную Unity training scene.
- [ ] Сравнить несколько seeds и оценить variance.

## Evaluation
Не оценивайте агента только по максимальному reward. Проверяйте поведение, robustness, unseen scenarios и воспроизводимость.
