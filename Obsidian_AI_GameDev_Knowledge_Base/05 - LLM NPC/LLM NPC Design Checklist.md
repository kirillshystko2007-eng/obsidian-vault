# LLM NPC Design Checklist

- [ ] Определены роль, мотивация и границы знаний NPC.
- [ ] Скрытое состояние игры не передаётся модели без необходимости.
- [ ] Игровые действия доступны только через allowlist.
- [ ] Ответ валидируется по схеме.
- [ ] Все изменения мира подтверждаются игровым кодом.
- [ ] Есть timeout и retry policy.
- [ ] Есть fallback без сети/модели.
- [ ] Память ограничена и редактируема.
- [ ] Есть защита от prompt injection.
- [ ] Проверены локализация, токсичность и возрастные ограничения.
- [ ] Измеряются latency, tokens, cost и failure rate.
- [ ] Игровой опыт не блокируется ожиданием LLM.
