# Сборки: ПК, мобилка, exe
Часть [[MM 00 - Обзор]]. Дополняет [[MM 01 - Файлы и сборка]].

## Папки 0.7 (`Desktop\monomoto 0.7\`)
| Папка | Для чего | Отличие |
|---|---|---|
| `mobile\` | телефон (PWA) | `PLATFORM = 'mobile'`, пиксели как в 0.6 (≈ 270 строк по короткой стороне) |
| `pc\` | компьютер | `PLATFORM = 'pc'`, пиксели мельче (≈ 420 строк); внутри `Mono Moto.exe` |
| `mono-moto-0.7.8-mobile.zip` | залить на хостинг | содержимое `mobile\` |

Исходник — `mobile\index.html`; ПК-версия получается из него заменой одной константы. Размер пикселя — константа `PIX_TARGET`. Настройки «Пиксели» в меню нет с 0.6 ([[MM 14 - Интерфейс и язык]]).

## Мобильная версия
Залить содержимое zip на любой https-хостинг → открыть в Safari → «Поделиться» → «На экран „Домой“». Работает офлайн (service worker, у каждой сборки своё имя кэша).

## exe (Windows)
- Набор для сборки: `Desktop\MM First build\` (раньше назывался `MonoMoto-exe`; там же `MMaudio` с исходными звуками) — `build.ps1` (собирает exe из папки игры встроенным в Windows компилятором C#), `make-platforms.ps1` (делает `pc\` из `mobile\`, собирает exe, пакует zip).
- Пересборка: `powershell -ExecutionPolicy Bypass -File make-platforms.ps1 -Root "C:\Users\Kira\Desktop\monomoto 0.7" -Version 0.7.8` (из папки `Desktop\MM First build`)
- exe — одно окно на движке WebView2 (Edge), без браузерных панелей; F11 / Alt+Enter — полный экран (запоминается). Сохранения общие для всех версий exe: `%LOCALAPPDATA%\MonoMoto\data`.
- exe без подписи — на чужих ПК Windows может показать «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».

Отладка и автотесты — [[MM 16 - Отладка]].
- Номер сборки: константа `BUILD`, её вписывает `make-platforms.ps1` из `-Version` и в меню, и в exe (0.7.1).
- С 0.7.8 у игры есть подпапка `music\` (песни Retro Wave). `build.ps1` вшивает в exe и подпапки, exe распаковывает их; `make-platforms.ps1` копирует папки в `pc\` и делает zip с путями через «/» (стандартный `Compress-Archive` в PowerShell 5.1 ломает папки на Linux/iPhone).
- 0.7.8 собрана целиком: exe 52,5 МБ (с песнями), мобильный zip 50,5 МБ. Исправлено в `make-platforms.ps1`: при повторной сборке `Copy-Item` вкладывал `music` внутрь старой папки (`music\music`, exe раздувался до 102 МБ) — теперь старая папка сначала удаляется.
