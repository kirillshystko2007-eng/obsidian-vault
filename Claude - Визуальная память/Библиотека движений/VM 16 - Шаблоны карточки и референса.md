## YAML-карточка движения
Копировать для новой карточки. Заполнять **только подтверждёнными данными**; неизвестное помечать `unknown` или `not_verified`.

```yaml
id: CMB-019
name: Heavy Greatsword Attack

category: combat
subcategory: heavy_weapon

rig:
  primary: R15
  compatibility:
    - R6_requires_retargeting
    - custom_rig_requires_mapping

style:
  supported:
    - realistic
    - stylized
    - anime
    - cartoon

duration:
  target_seconds: 1.4
  fps: 30
  source_measured: false

motion:
  intent: powerful_heavy_attack
  weight: heavy
  intensity: high
  direction: overhead_diagonal

phases:
  - name: anticipation
    frames: [0, 8]
    timing_status: proposed
  - name: windup
    frames: [8, 17]
    timing_status: proposed
  - name: acceleration
    frames: [17, 23]
    timing_status: proposed
  - name: impact
    frames: [23, 25]
    timing_status: proposed
  - name: follow_through
    frames: [25, 31]
    timing_status: proposed
  - name: recovery
    frames: [31, 42]
    timing_status: proposed

body_mechanics:
  hip: weight_transfer_and_rotation
  spine: rotational_force_transfer
  shoulders: weapon_guidance
  elbows: trajectory_control
  wrists: grip_stability
  legs: balance_and_support
  head: target_tracking

quality:
  require_weight: true
  require_follow_through: true
  require_readable_impact: true
  require_transition_review: true

reference:
  url: null
  creator: unknown
  license: unknown
  verified: false

verification:
  code_review: required
  visual_preview: required
  foot_contact_review: required
  reviewer_notes: null
```

## Карточка проверки внешнего референса
Каждый внешний материал получает собственную запись:

```yaml
reference_id: REF-CMB-019-001
motion_id: CMB-019

source:
  url: ""
  title: ""
  creator: unknown
  publisher: unknown
  publication_date: unknown
  access_date: ""
  license: unknown
  usage_permissions: not_verified

media:
  type: video
  duration_seconds: unknown
  fps: unknown
  camera_view: unknown

analysis:
  key_poses: []
  phases: []
  measured_timing: []
  estimated_timing: []
  body_mechanics: []
  contact_points: []
  center_of_mass_observations: []

roblox_adaptation:
  target_rig: R15
  joint_mapping: []
  limitations: []

quality:
  source_verified: false
  license_checked: false
  motion_observed: false
  analysis_reviewed: false

notes: ""
```

## Правила работы с референсами
- Не придумывать URL, автора, лицензию, FPS или дату публикации.
- Отличать непосредственно наблюдаемые факты от интерпретации.
- Тайминг, измеренный по кадрам, хранить отдельно от приблизительной оценки.
- Наличие ролика ≠ разрешение на копирование или распространение.
- Предпочитать официальные, открыто лицензированные или явно разрешённые материалы.
- При неизвестной лицензии — материал **reference-only**, не включать в распространяемые ассеты.
- Для каждого анализа сохранять источник и дату проверки.
