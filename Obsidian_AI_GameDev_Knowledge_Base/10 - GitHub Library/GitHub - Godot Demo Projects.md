# GitHub - Godot Demo Projects

**Repository:** https://github.com/godotengine/godot-demo-projects  
**Назначение:** официальные демонстрационные и шаблонные проекты Godot.

## Подтверждённые сведения
README описывает репозиторий как коллекцию демонстрационных и template projects. Ветки соответствуют разным версиям Godot; master может соответствовать development branch. README указывает MIT License.

## AI/navigation example
`2d/navigation_astar` демонстрирует grid-based pathfinding с AStarGrid2D. Описание проекта указывает Steering Behaviors для сглаживания движения.

Пример: https://github.com/godotengine/godot-demo-projects/tree/master/2d/navigation_astar

## Практика
1. Выберите ветку под вашу версию Godot.
2. Скачайте/клонируйте репозиторий.
3. Импортируйте проект через Project Manager.
4. Изучите AStarGrid2D и обработку препятствий.
5. Сравните маршрут и фактическое движение.
