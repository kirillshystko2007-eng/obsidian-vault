# Unity AI / Игровой ИИ в Unity

## Классический AI
- C# state machines и decision systems.
- NavMesh и NavMeshAgent для навигации.
- Physics queries для perception.
- ScriptableObjects для конфигурации и data-driven поведения.
- Gizmos/Handles для визуальной отладки.

## ML-Agents
Официальный Unity ML-Agents Toolkit позволяет использовать игры и симуляции как среды для обучения интеллектуальных агентов посредством deep reinforcement learning и imitation learning.

В документации описаны:
- Learning Environment.
- Python API и trainer.
- PPO и SAC.
- Behavioral Cloning и GAIL.
- Self-play и multi-agent scenarios.
- Curriculum learning и environment randomization.

## Начать
1. Открыть [[GitHub - Unity ML-Agents]].
2. Прочитать официальный overview и installation guide.
3. Проверить совместимость Unity/Python по текущей документации.
4. Запустить пример из репозитория.
5. Создать собственную простую среду.

Не фиксируйте версии из старых tutorial без проверки. Официальная документация указывает совместимые версии для конкретного релиза.
