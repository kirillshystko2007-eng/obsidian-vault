# PE Дизайн 05 — Монстры

Хаб: [[PE Дизайн 00 — Видение и игровой цикл]] · цель: G12 в [[PE_Goals_00_Roadmap]] · текущие зомби: [[PE 12 - Зомби]]

## Решено
- **Зомби — лишь один из монстров**, позже появятся другие.
- **Заражение не распространяется** (ни на игроков, ни по миру) — «пандемия» пока только сеттинг.

## Что есть
- `ServerStorage.ZombieTemplate.Zombie` + скрипт `ZombieBrain` (агр, блуждание, рывок), `ZombieSpawner` (до 3 на локацию, просыпаются в 230 студах), награда через атрибут `Bounty` → `KillTracker`.
- Анимации: процедурные `ZombieWalk/ZombieIdle/ZombieAttack` (`ServerStorage.ProcAnim`), смерти `DeathAnimations`, зоны попаданий `HitZones` (голова = убийство).

## Монстр №2 — Оборотень (сделан 2026-11-09)
Решение пользователя: «добавить оборотней». Только ночью, по одному в диких локациях (Bloodwood Mill, Blackthorn Estate, Hollow Saint, Rotting Acres, Blackwater Bayou, Widow's Mine); вой перед охотой, погоня 17, прыжок, когти; 260 HP, урон 22; голова ×2.5 (не мгновенно); награда $75. Подробно: [[PE Отчёт 2026-11-09 — G12, оборотни]].

## Идеи (не утверждено, для обсуждения)
Ночной «вендиго» в лесах Bloodwood, шахтёрские твари в Widow's Mine, болотные утопленники в Blackwater Bayou, бронированный «мясник» как элита для охоты за головами.
